One Line, One Chill — a single original horror sentence, under 200 characters, written to be frightening first, vivid second, and original third. No mirror, no doll, no basement: a hospice nurse, a 3 a.m. death log, and her own voice reading it back over the ward intercom.

## Run it

```sh
python3 main.py
```

It writes the line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`), validating the gate first: 1–200 characters, a single line, non-blank, valid UTF-8.
